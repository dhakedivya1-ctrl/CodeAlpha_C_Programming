# CodeAlpha C Programming Internship Tasks

This repository contains completed C programming tasks for the CodeAlpha internship.

## Completed Tasks

### Task 1 – Basic Calculator
Performs:
- Addition
- Subtraction
- Multiplication
- Division

Uses switch-case for operation selection.

### Task 2 – Matrix Operations
Performs:
- Matrix Addition
- Matrix Multiplication
- Transpose

Uses functions and 2D arrays.

### Task 3 – Student Management System
Features:
- Add student
- Delete student
- Update student
- Search student
- Display student records

Uses structures and file handling for permanent storage.

## How to Run

Compile any `.c` file using a C compiler such as GCC:

`gcc filename.c -o program`

Then run the generated program.
